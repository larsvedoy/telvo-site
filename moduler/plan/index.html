Telvo Planmodul

Databasert plan- og medvirkningsløsning for kommunen – samskriving i Power Apps, høringer med innspill, publisering som nettportal og oppfølging med indikatorer og tiltak.

Formål og bakgrunn

Telvo Planmodul gjør planarbeidet i kommunen datadrevet i stedet for dokumentdrevet. Innhold lagres som strukturerte data (mål, strategier, tiltak, kapitler, indikatorer), som kan gjenbrukes, kobles til budsjett og publiseres på nett. Slik får dere bedre samhandling, ryddigere begrepsbruk og raskere publisering – uten tunge Word/PDF-runder.

Modulen er bygget for kommuneplaner og temaplaner, men kan også brukes for strategier og handlingsplaner i virksomhetsområder. Målet er en moderne planplattform der innbyggere, politikere og ansatte enkelt kan lese, bidra og følge opp.

Arkitektur og teknologi

Power Apps (Teams-integrert): hovedappen for skriving, strukturer og prosess. Modell-drevet UI for stabilitet og gode lister/relasjoner.

Dataverse: databasen for planinnhold (Plan, Kapittel, Mål, Strategi, Tiltak, Indikator, Innspill, Versjon m.m.) med relasjoner og rollebasert sikkerhet.

Power Pages: planportal for ekstern publisering av utkast og vedtatte planer – universelt utformet og mobilvennlig.

Power Automate: arbeidsflyt for høringer, varsler, versjonsmerking, publisering og oppgaveflyt.

Power BI: dashboards for status og utvikling (indikatorer, framdrift, antall innspill, prosessstatus).

SharePoint: dokumentbibliotek for vedlegg (utredninger, bilder, notat), koblet til planobjekter.

Brukerroller og medvirkning

  • Planleggere/administrasjon: samskriver planinnhold i appen, gjenbruker maler og struktur, knytter tiltak til mål og indikatorer.
  • Politikere: leser utkast (enkelt grensesnitt), kommenterer i frister og følger høringsversjoner via portalen.
  • Innbyggere: leser publiserte planer og sender inn strukturerte innspill i høringer (med enkel moderering).
  • Arbeidstakerorganisasjoner: får dedikert innspillsløp ved behov (intern høring), status og tilbakemeldinger.
  • Ledelse: følger porteføljeoversikt: prosessfaser, frister, antall innspill, tiltaksgjennomføring.

Prosess og arbeidsflyt

Planmodulen støtter hele livssyklusen – fra idé til vedtak og oppfølging:

  • Oppstart og struktur: velg mal (samfunnsdel/temaplan), opprett planobjekt med meta (formål, tidsramme, ansvar), og generer kapittelinndeling.
  • Samskriving: flere kan redigere ulike deler samtidig. Begreper standardiseres via felt og malterminologi. Versjonshistorikk lagres.
  • Medvirkning/høring: sett planen i høringsmodus, publiser utkast til Power Pages, samle innspill via skjema (knyttes til kapittel/tema), moderer og merk status (“vurdert”, “innarbeidet”, “avvist – begrunnelse”).
  • Politisk behandling: del konsis leservisning med beslutningsgrunnlag (mål, konsekvenser, kost/nytte). Varsler om frister i Teams/e-post.
  • Vedtak og publisering: frys versjon, publiser vedtatt plan som nettrapport med søk, kapittelnavigasjon og eventuelle grafer.
  • Oppfølging: koble tiltak til indikatorer og (valgfr.) budsjettposter; følg framdrift i dashboard; generer årsrapporter.

Nøkkelfunksjoner

  • Strukturert planinnhold: datafelter for mål/strategi/tiltak/indikator – ikke fritekst i dokumenter.
  • Maler og standardbegreper: konsistent terminologi og kapitler på tvers av plantyper og sektorer.
  • Relasjoner og “rød tråd”: tiltak → mål → indikatorer; lenk videre til budsjett og virksomhetsplaner.
  • Versjoner og endringslogg: utkast, høringsversjon, vedtatt; automatisk diff/logg mellom versjoner.
  • Høring og innspill: strukturert skjema, statusflyt, moderering og offentlig/innlogget høringsløp ved behov.
  • Publisering på nett: Power Pages-portal med UU, søk, kapittelnavigasjon og ev. indikator-grafer.
  • Dashboards: portefølje og per plan (framdrift, innspill, indikatorer, frister, ansvarlige).
  • Eksport: generer PDF/Word ved behov, med maler som sy sammen databasen til rapportformat.

Sikkerhet, deling og publisering

Tilgang: Azure AD-innlogging og Dataverse-roller (f.eks. planforfatter, intern leser, moderator). Utkast kan skjermes internt; publisering styres per plan/fase.

Logging og sporbarhet: endringer, kommentarer og innspill logges. Modereringsstatus er etterprøvbar.

Personvern: innspill kan anonymiseres i publisering. Portalen kan åpnes uten innlogging eller beskyttes (ID-porten/Azure AD B2C) ved behov.

Universell utforming: portalen følger WCAG-prinsipper og fungerer på mobil, nettbrett og desktop.

Konkurransefortrinn og videreutvikling

  • Dyp M365-integrasjon: Teams-app, felles innlogging, SharePoint-vedlegg, Power BI-innsikt.
  • Medvirkning som standard: høringer og innspill innebygd i samme løsning som skriving og publisering.
  • Helhetlig styring: koblinger til budsjett/økonomi og virksomhetsplaner gir rød tråd fra mål til gjennomføring.
  • Lavkode og skalerbar: maler og tabeller kan tilpasses lokalt; kommunen eier data og kan bygge videre.
  • Sanntidsoppdatering: publisert innhold henter direkte fra databasen – unngå manuelle eksportløp.

Videreutvikling kan inkludere automatisk generering av presentasjoner for folkemøter, AI-assistert forenkling av språk, eller tettere kobling mot GIS og planregister for arealplaner.
